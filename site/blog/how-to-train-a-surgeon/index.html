A question in two stages

Surgical understanding spans several kinds of reasoning: recognizing an instrument, identifying an action, locating a scene within an operation, and assessing the quality of a procedure. A model that succeeds at one may still struggle with another.

Our paper starts by diagnosing these capabilities in general-purpose multimodal models. It then asks whether agents can improve at inference time by seeking knowledge and grounding visual evidence, without additional surgical training. The quotation marks around “train” point to that distinction: the intervention here is access to an environment and tools.

This companion follows the paper’s two stages. The full paper contains the protocols, comparisons, and detailed results.

First, find the boundary

SurgKnow-Bench—SurgKnowBench in the paper—harmonizes 11 public datasets across seven surgical procedures and seven task axes. Its 376,602 samples organize surgical understanding into three families:

  • Spatial recognition: tool detection, tool localization, and instrument–verb–target triplets.
  • Temporal reasoning: phase and action recognition.
  • Workflow assessment: critical-view-of-safety and surgical skill assessment.

Stage I evaluates direct answers to establish what pretrained models can do on their own. Keeping the task families visible matters: an aggregate score can hide a model that recognizes objects but fails to understand their relations or the procedural context.

Reading route: Section 2 for the benchmark; Appendix C for construction and metrics.

Then, make evidence accessible

SurgAgentGym provides the environment for Stage II, evaluated on the 952-sample SurgKnowBench-Hard subset. The agent receives a task, visual input, an answer contract, and bounded access to tools.

See
The visual grounding tool returns region proposals and a numbered overlay of the current input. The agent still has to interpret what those regions mean.
Search
The retrieval tool queries SurgWiki, drawing on textbooks, guidelines, tutorial videos, and case records.
Submit
The agent combines its observations into a final answer. The harness enforces the tool interface and budgets, and records the trajectory.

The projects have different roles: SurgKnow-Bench defines the evaluation tasks; SurgAgentGym executes the interaction; SurgWiki supplies knowledge; SurgAgent is the reference agent. A trajectory connects them by showing what the agent did with the evidence it could access.

Reading route: Sections 3 and 4.1 for tools and the harness; Appendix D for implementation.

Tools help, unevenly

The results show partial surgical competence in pretrained models and task-dependent gains from agentic inference. Improvements are most consistent in perception-heavy recognition tasks. Fine-grained localization, relational understanding, and expert-style assessment remain difficult.

Two comparisons answer different questions. The across-stage comparison measures the move from direct answers to the full agent setting. The matched tool comparison holds the agent setup and prompts fixed while switching tool access off and on. The latter is the more focused test of the contribution of tools.

Improvement also needs to be read alongside absolute performance. Likewise, an apparently strong assessment accuracy may reflect common rubric values rather than meaningful agreement with expert judgments. The paper reports task-specific metrics and analyzes these failure modes.

Reading route: Section 2.3 for the diagnostic findings; Section 4.2 and Table 3 for the agent comparisons; Appendix E for extended results.

From evidence use to improvement

The current paper establishes the benchmark and the agentic environment. VITAgent’s wider research direction asks how an agent might learn from its own attempts and improve how it uses that environment.

SurgAgentEvolve explores this next step toward recursive surgical superintelligence. It is ongoing work; recursive improvement is a research direction beyond the results reported in this preprint.
